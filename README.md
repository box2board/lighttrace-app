# LightTrace (Expo React Native)

A clean starter structure for the **LightTrace** mobile app.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Expo:
   ```bash
   npm start
   ```

You can then run on iOS, Android, or web from the Expo interface.

## Project Structure

- `App.js` – app entry point and navigation container setup.
- `navigation/` – app navigation configuration.
- `screens/` – placeholder app screens.
- `components/` – reusable UI components (future).
- `hooks/` – custom React hooks (future).
- `utils/` – helper functions (future).
- `constants/` – shared app constants and design tokens.
- `assets/` – static assets like icons and images.
